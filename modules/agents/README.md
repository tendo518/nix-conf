# Agent configuration

Provider credentials, endpoints, model catalogs, and routing are managed by
Magpie. Nix modules only write each Agent's own non-provider settings and
package/wrapper configuration.

After changing an Agent's base configuration, apply the Nix generation and let
Magpie inject the selected provider/model into the Agent:

- Codex: `~/.config/codex/config.toml`
- Claude Code: `~/.claude/settings.json`
- Claude Desktop: package only
- Pi: `~/.pi/agent/settings.json`
- OMP: `~/.omp/agent/config.yml`
- DeepSeek Harness: package only
- Reasonix: `~/.reasonix/config.toml`

Provider-specific files such as Pi `models.json`, OMP `models.yml`, Magpie
Codex profiles/catalogs, Reasonix `providers`, and DSH profile providers are
not generated by Nix.
